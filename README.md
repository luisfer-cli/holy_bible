## Bible implemented on Holy C

In honor to Terry A. Davis 1969-2018

Main functions:

- Print on std output a versicule of bible

´´´bash

bible-cli genesis 25 2 # print genesis capitule 25 versicule 2

´´´

- Print on std output a book of bible

´´´bash

bible-cli genesis

´´´

- Print on std output a capitule of bible

´´´bash

bible-cli genesis 25

´´´

- Print a random versicule of bible

´´´bash

bible-cli -r

´´´

- See help
  ´´´bash

bible-cli --help

´´´

- See version

´´´bash

bible-cli --version

´´´
